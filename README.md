# Sangrita Tech

Сайт компании и лендинг Wardrones DC. Статические HTML и CSS, без сборки и внешних скриптов. Работают с клавиатурой и на мобильных экранах. Разделы переключаются обычными ссылками, поэтому доступны без JavaScript и имеют отдельные адреса.

- Главная страница находится в index.html.
- Лендинг игры находится в wardrones-dc/index.html.
- Общие стили и оптимизированные изображения находятся в assets.

Сайт публикуется через GitHub Pages из ветки main. Материалы созданы для Sangrita Tech. Промоарт и кадры взяты из собственных материалов Wardrones DC. Этот репозиторий не содержит исходников игры или пользовательских данных.

При изменении Telegram-бота обнови ссылки на обеих страницах. Публикация выполняется после проверки файлов workflow Pages.
